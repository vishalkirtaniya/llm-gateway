Acme API rate limits are set to 100 requests per minute for each user. If a client exceeds the limit, the server returns HTTP 429, and the client should retry with exponential backoff. Authentication uses JWT access tokens that expire after 15 minutes. Refresh tokens stay valid for 7 days and are stored in an HttpOnly cookie. List endpoints use cursor-based pagination and return at most 100 items per page. All errors use one JSON envelope with a code, a message, and a request id.
